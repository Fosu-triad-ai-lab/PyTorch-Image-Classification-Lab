## 一、选题

**基于图像数据的产品缺陷预测建模**（大纲原文点名的方向之一）。

选用 **Severstal 钢板表面缺陷数据集**（Kaggle 2019 真实工业赛题）：

- 训练集 12950 张钢板灰度图（256×1600），其中约 6:1 为无缺陷:有缺陷；4 类缺陷（SeqNo 1～4）带像素级 RLE 标注；官方 test 集 1800 张**无标签**。
- 下载走 hf-mirror 镜像（节点可直连）：`Voxel51/severstal_steel_defects`，下载方法见下文「数据获取」。
- 选它的理由：镜像直接可得（不依赖网盘/GitHub）；数据量适中，GB10 上训练极快；真实工业背景，缺陷分布极不平衡，正好引入数模味道的处理手段；可完全复用实验1 的训练/评估代码框架。

备选数据集（若 Severstal 下载或使用遇阻）：NEU-DET（东北大学钢材缺陷，1800 张 6 类，需本机下载后 scp 传节点）、DefectSpectrum（hf-mirror 可得）。

## 二、模型假设（数模论文素材，先记录在此）

1. 官方 test 集无标签，无法计算指标 → 从 12950 张带标注图内部按 **7 : 1.5 : 1.5** 划分 train/val/test（固定种子 42），test 仅最终评估一次。
2. 一张图可能同时含多类缺陷 → 按**多标签分类**建模，输出层 Sigmoid + 二元交叉熵（BCE），而非 Softmax。
3. 类别不平衡（无缺陷图约占 6/7）→ 训练时按类别频率加权 BCE 损失，并在论文中给出损失函数的数学表达。
4. 判定"该图含第 k 类缺陷"的 Sigmoid 阈值不在训练中固定为 0.5，而是**在验证集上搜索最优阈值**，测试集只用搜索结果评估一次。
5. 数据增强仅使用不改变缺陷类别语义的几何/亮度变换（翻转、小角度旋转、亮度抖动）。

## 三、技术路线

| 环节 | 内容 |
| --- | --- |
| 数据获取 | hf-mirror 下载 Severstal → RLE 解码为 mask → EDA（缺陷类别分布、面积分布、示例图） |
| 主模型 | ImageNet 预训练 ResNet18 微调，多标签 4 类输出（复用实验1 训练框架：argparse、种子 42、保存验证最优、每轮打印） |
| 对比实验 | ① ResNet18 vs ResNet34；② 微调 vs 冻结骨干；③ ViT 对比组（torchvision 自带预训练权重，回应"transformer 是否碾压 CNN"）；④ 传统方法对照：Otsu 阈值分割 + 形态学特征 + 逻辑回归 |
| 阈值优化 | 在验证集上对每类独立搜索最优判定阈值（F1 最大） |
| 灵敏度分析 | 最优阈值 ±0.05/±0.10 扰动对 F1/IoU 的影响，检验结论稳定性 |
| 评价指标 | 逐类 F1、总体 macro-F1、IoU/Dice（若做分割）、混淆矩阵、各类别准确率；论文"模型建立"节给出 BCE、F1、Dice 的符号表与公式 |
| 论文 | 按竞赛规范：摘要、问题重述、模型假设、模型建立、模型求解、结果分析、模型评价与改进；最终稿放 `docs/` |

创新点（对应大纲"项目完成质量 25 分"中的创新项）：温度/阈值这类"看似超参实则建模决策"的系统分析、传统 CV 方法与深度模型的同口径对比、ViT vs CNN 在工业小数据上的实证。
