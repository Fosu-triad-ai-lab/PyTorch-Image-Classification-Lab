## 二、实验1（基于 PyTorch 的图像分类）

### 概念题（必须能一句话说清）

| 概念 | 参考答案 |
| --- | --- |
| 卷积层 | 局部感受野 + 权值共享提取空间特征，参数量 = 输入通道×输出通道×k×k |
| BatchNorm | 对每个通道做标准化，稳定激活分布 → 收敛更快、可用更大学习率 |
| Dropout | 训练时以概率 p 随机置零神经元，防止共适应，起正则化作用 |
| 交叉熵损失 | 分类任务标准损失，配合 Softmax，输出概率分布的负对数似然 |
| 数据增强 | RandomCrop(32, padding=4)、RandomHorizontalFlip，扩充多样性抑制过拟合 |
| 过拟合/欠拟合 | 训练准确率高、验证低 = 过拟合；两者都低 = 欠拟合 |
| 混淆矩阵 | 行=真实、列=预测，对角线越高越好，能看出哪些类互相混 |

### "为什么"题（高频）

- **为什么加 BN 快了？** BN 缓解激活分布漂移，第 1 轮验证准确率 23.14%→45.68%，可以用 0.05 的大学习率放心训。
- **为什么加了 Dropout 反而掉？** 20 轮预算内过拟合本来不严重（训练/验证只差约 4.5pp），且已有随机裁剪+翻转增强，Dropout 拖慢收敛的代价超过正则化收益——正则化不是无脑加的。
- **为什么存验证集最优而不是最后一轮？** 防止把过拟合那一轮存下来。
- **为什么猫狗最容易混？** 32×32 低分辨率下毛发纹理、体型相似，cat→dog 108 张。
- **Dropout 组训练准确率为什么偏低？** 统计时 Dropout 开启中（`model.train()`），不能直接和验证准确率比较，判断泛化看验证/测试。

### 必背数字

| 配置 | BN | Dropout | 测试准确率 |
| --- | --- | --- | --- |
| 基准 | 否 | 否 | 87.82% |
| **+BN（最佳）** | 是 | 否 | **90.21%（+2.39pp）** |
| +Dropout | 否 | 是 | 86.65% |
| +BN+Dropout | 是 | 是 | 88.13% |

其他：CIFAR-10 共 6 万张 32×32 彩色图、10 类；官方训练集按 9:1 划分（训练 45000 / 验证 5000）、测试 10000；模型约 3.25M 参数；SGD momentum 0.9、weight decay 5e-4、余弦退火、初始 lr 0.05、batch 128、20 轮、种子 42；最易混类别对 cat→dog 108 张、dog→cat 71 张。

## 三、实验2（基于 PyTorch 的文本情感分类）

### 概念题

| 概念 | 参考答案 |
| --- | --- |
| Embedding | 把词映射成稠密向量，可训练的查找表 |
| 词表构建 | 只用训练集、词频≥2、取前 2 万，`<pad>`=0、`<unk>`=1 兜底未登录词 |
| LSTM | 门控循环网络（遗忘/输入/输出门），缓解 RNN 梯度消失，能保留长距离依赖 |
| 梯度裁剪 | max-norm 5.0，防 LSTM 梯度爆炸 |
| 截断 256 词 | 超长评论截断，测试集 27.9% 超过窗口 → 长文本错误的主因 |
| pack_padded_sequence | 变长序列按真实长度打包，LSTM 取真实最后时刻隐状态 |

### "为什么"题（本实验的灵魂）

- **为什么随机初始化反而赢了 GloVe？** 数据量够（2.25 万）+ 全量微调：预训练词向量的收益场景是"小数据或冻结向量"；GloVe 收敛快（第 2 轮领先 +12.8pp）但训练拟合太快，验证 loss 从第 5 轮的 0.313 回升到第 9 轮的 0.429 → 更早过拟合，最终泛化更差。
- **为什么替换噪声比删词伤？** 删词只是信息变少，剩余语义不变；替换是往句子里注入语义无关的"合法词"，每一步隐状态都被污染。p=0.4 时替换降 8.3pp、删词只降 4.2pp。
- **为什么 GloVe 模型对替换噪声更脆弱？** 判别更依赖词的语义身份，随机词的语义与上下文剧烈冲突（报告里注明这是基于现象的推测，未做对照验证——答辩可主动说明）。
- **错例四类**：讽刺反语（字面全是褒义的差评）、前褒后贬混合情感、长文本截断丢结论、高生僻词占比；还有少量标签噪声。

### 必背数字

| 配置 | 测试准确率 | 测试损失 |
| --- | --- | --- |
| **随机初始化（最佳）** | **87.73%** | 0.2999 |
| GloVe 初始化 | 85.85% | 0.4765 |

其他：IMDB 25000+25000，内部 9:1 切分（训练 22500 / 验证 2500），测试集只做最终评估；Embedding 100 维、LSTM hidden 128 单层、约 2.12M 参数；Adam lr 1e-3、weight decay 1e-4、10 轮、batch 64；GloVe 6B.100d 命中率 95.75%；噪声实验 p∈{0, 0.1, 0.2, 0.3, 0.4}。

## 四、实验3（图像与文本多模态检索）

### 概念题

| 概念 | 参考答案 |
| --- | --- |
| 双塔结构 | 图像、文本各自编码 → 投影到共享嵌入空间 → 余弦相似度匹配 |
| InfoNCE | 对比学习损失：正对拉近、batch 内其他当负样本推远，除以温度 τ=0.07 |
| 温度缩放 | 把相似度差放大约 14 倍，梯度信号变强——**本实验的核心发现** |
| Triplet loss | relu(margin − 正对 + 最难负对)，本实验三组全不收敛，根因是缺温度缩放 |
| Recall@K | 前 K 个检索结果里包含真值的比例；一张图 5 条描述，任意一条进 top-K 即命中 |
| 迁移学习 | 用 ImageNet 预训练 ResNet18 提特征、预训练 BERT 提文本特征，小数据也能用 |
| 微调 vs 冻结 | 微调让预训练权重向任务靠拢；冻结只能靠投影头适配 |
| L2 归一化 | 向量归到单位球面，点积即余弦相似度 |

### "为什么"题（高频）

- **为什么 triplet 全挂了？** train_loss 从 0.236 缓慢降到 0.204 后不动，恰好卡在 margin(0.2) 附近：初始两路嵌入挤在归一化球面同一窄锥里，原始余弦相似度梯度太弱，学习率×5、30 轮也拉不开——结论：余弦空间做对比学习，温度缩放不能省。
- **为什么图像塔冻结？** ResNet18 特征离线预计算（预计算约 8 秒），每 epoch 约 1 秒，对比实验便宜，也符合大纲"调用预训练 CNN 提取特征"的要求。
- **为什么微调 BERT 好？** 同口径（d512、10 epoch）下 16.20% vs 冻结 9.60%（+6.60pp）；小数据下微调 4.39M 的 tiny 模型没观察到过拟合。
- **主要误差是什么？** 失败样本里 40.8% 的真值仍在 top10 内——"近失败"占主导，短板是细粒度属性（年龄/颜色/动作）和相近描述间的排序分辨力。
- **为什么只有 17.7%？** 文本编码器是 4.39M 的 BERT-tiny，重点在流程与对比分析而非刷指标；更大模型在 Flickr8k 上 R@1 普遍 30%+（报告局限里写了）。

### 必背数字

| 配置 | I2T R@1 | I2T R@10 |
| --- | --- | --- |
| 基线 d256/10ep | 12.30% | 47.70% |
| d512/10ep | 16.20% | 48.10% |
| **d512/30ep（最佳）** | **17.70%** | **51.30%** |
| 冻结 BERT（d512/10ep） | 9.60% | 40.50% |
| triplet 三组 | ≤0.3% | ≈1% |

其他：Flickr8k 8091 图、每图 5 条描述、6000/1000/1000 划分；候选池 1000 图 / 5000 描述；最佳配置 I2T 中位排名 10、T2I 中位排名 11；8 组对比共 8 次训练，单组 10～30 秒；全模型可训练参数约 5.24M。

## 五、跨实验通用八股

- **为什么固定种子 42？** 固定 Python / NumPy / PyTorch / CUDA 随机性，保证结果可复现。
- **训练/验证/测试集分工？** 训练集调参学习，验证集选模型，测试集只在最后评估一次。
- **`model.train()` 和 `model.eval()` 区别？** train 开启 BN 更新与 Dropout；eval 冻结它们。
- **epoch / batch / iteration？** 一个 epoch = 过完一遍训练集；一个 batch 一次前向反向。
- **loss 不降/爆炸怎么办？** 查学习率、梯度裁剪、数据与标签、BN；实验2用了梯度裁剪 5.0。
- **为什么用 GPU 跑？在哪跑？** DGX Spark 云节点（GB10、121GB 统一内存），长任务放 tmux，环境 `~/venvs/cnn`（Python 3.12 + torch 2.14.1+cu130）。
- **怎么保存/加载模型？** 保存验证集最优的 `state_dict` 到 `checkpoints/*.pth`（不进 Git）。
- **绝对准确率为什么会有小波动？** 单随机种子、未做多次重复实验（三份报告局限里都写了，主动讲出来更体面）。
